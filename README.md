# Fraud and Account-Takeover Detection for Fintech

## 📌 Project Overview

An AI-powered fraud detection system designed to identify suspicious financial transactions and help fintech companies reduce fraudulent activities while minimizing false declines of legitimate transactions.

The project focuses on applying machine learning techniques to financial transaction data to distinguish between legitimate and fraudulent activities.

## 🎯 Objectives

- Detect fraudulent financial transactions.
- Reduce financial losses caused by fraud.
- Minimize false positives and unnecessary transaction declines.
- Explore machine learning techniques for fraud detection.
- Investigate account-takeover detection as a potential extension.

## 📊 Dataset

**ULB Credit Card Fraud Detection Dataset**

The dataset contains anonymized credit card transactions labeled as legitimate or fraudulent.

Source: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
